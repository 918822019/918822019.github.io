如何维护文档

  1. 在 docs/ 下创建子目录并添加 Markdown 文档。
  2. 更新 docs/index.json 结构（见目前示例）。
  3. Git 提交后，GitHub Pages 会自动更新站点。

自动生成目录

本仓库包含自动生成 docs/index.json 的机制：

  1. build-docs-index.js 会递归扫描 docs/，生成树状结构 JSON。
  2. 在 push 到 doc 时，GitHub Actions 工作流会执行并发布站点。
