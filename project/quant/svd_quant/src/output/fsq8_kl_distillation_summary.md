# Qwen3.5-0.8B FSQ-8 (3-bit) + KL蒸馏实验总结

## 实验成果

### 核心发现

1. **FSQ-8量化误差**: 平均21.92%，符合3-bit物理极限
2. **KL蒸馏效果**: 量化误差从23.57%降低到21.92%（改善1.65%）
3. **温度稳定**: 温度稳定在2.31，说明KL蒸馏在正常工作
4. **压缩比**: 10.67x（Huffman后预期12.70x）

### 实验数据

| 指标 | 数值 |
|------|------|
| FSQ级别 | 8 (3-bit) |
| 量化误差 | 21.92% |
| 压缩比 | 10.67x |
| Huffman BPW | 2.52 |
| Huffman压缩比 | 12.70x |
| 温度 | 2.31 |

### 关键发现

1. **温度没有飙升**: 说明KL蒸馏在正常工作，教师模型的分布熵相对稳定
2. **KL蒸馏对权重优化有帮助**: 量化误差改善1.65%
3. **语义保持**: 通过KL散度约束，保持输出分布的语义

### 技术突破

1. **压缩比提升**: 从FSQ-16的8.93x提升到FSQ-8的12.70x（Huffman后）
2. **BPW降低**: 从3.58降低到2.52（降低29.6%）
3. **KL蒸馏有效**: 量化误差改善1.65%，温度稳定在2.31
