# 端侧 LLM 架构设计

## 硬件约束（家庭中枢类设备）

| 指标 | 约束值 | 说明 |
|---|---|---|
| 功耗 | < 35W | 插电运行，但散热有限 |
| 内存 | 24-48 GB | Mac Mini / NUC 级别 |
| 存储 | 512GB+ | 本地索引 + 模型 |
| 内存带宽 | ~200 GB/s | UMA（统一内存） |
| NPU | 可选 | Mac ANE / Intel NPU |
| 推理时延 | < 2s | 非实时，可接受延迟 |
| 价格 | 7-8k RMB | 家庭中枢整机预算 |

## 设计原则

1. **硬件先于模型** — 每层设计时标注目标执行单元（CPU/NPU/DSP）
2. **量化内建** — 从定义层开始就带 scale/zero_point，不做事后 PTQ
3. **剪枝内建** — 每层自带可学习的 mask，训练时自动决定剪哪里
4. **无 HBM 假设** — 不假设内存无限快，显式管理 activation 的流向

## 场景驱动：家庭视频检索

- 输入：摄像头 24/7 视频流，抽帧处理
- VLM 任务：帧描述 + 物体检测 + 文本索引
- 检索：自然语言查询 → 向量检索 → 时间戳定位
- 全部本地执行，不出设备

## 模型定位

- 目标参数量：3-7B（4-bit 量化后 ~2-4 GB）
- KV cache 优化：DSv4 混合注意力 + Linear Attention（详见 `1.混合注意力设计.md`）
- 融合视觉输入：接视觉 encoder，端侧推理
